# Registro de specs

Toda tarefa passa por uma spec (SDD). Criar a partir de `TEMPLATE.md` como `NNN-<slug>.md` e registrar aqui.
Specs nunca são apagadas; descartadas ficam `cancelled` com motivo.

Status: `draft` → `approved` → `in_progress` → `review` → `done` (ou `cancelled`).
